Orchestration de Pipeline Data avec Kestra

Présentation du projet

Mise en place d'un pipeline de données complet orchestré avec Kestra, incluant la détection et résolution de goulots d'étranglement, ainsi que des workflows automatisés. Ce projet comprend :

  • Orchestration de workflows : conception et déploiement de pipelines de données avec Kestra via des fichiers YAML déclaratifs
  • Détection de bottlenecks : identification et optimisation des étapes bloquantes dans le pipeline de données
  • Tests automatisés : mise en place de suites de tests pour valider chaque étape du pipeline
  • Containerisation : déploiement de l'environnement complet avec Docker

Technologies utilisées

  • Kestra (orchestration de workflows)
  • Python
  • Docker / Docker Compose
  • YAML (définition des workflows)
  • ETL / Data Pipeline

Extrait du workflow


# workflow.yaml – Pipeline principal Kestra
id: pipeline_data_principal
namespace: endaye.projet10

tasks:
  - id: extraction_donnees
    type: io.kestra.plugin.scripts.python.Script
    script: |
      import pandas as pd
      df = pd.read_csv("data/raw/input.csv")
      df.to_parquet("data/staging/extracted.parquet")

  - id: transformation
    type: io.kestra.plugin.scripts.python.Script
    dependsOn: [extraction_donnees]
    script: |
      import pandas as pd
      df = pd.read_parquet("data/staging/extracted.parquet")
      df_clean = df.dropna().drop_duplicates()
      df_clean.to_parquet("data/output/transformed.parquet")

  - id: validation_qualite
    type: io.kestra.plugin.scripts.python.Script
    dependsOn: [transformation]
    script: |
      import pandas as pd
      df = pd.read_parquet("data/output/transformed.parquet")
      assert df.shape[0] > 0, "Le pipeline a produit un résultat vide"
      print(f"Pipeline OK – {df.shape[0]} lignes traitées")

triggers:
  - id: schedule_quotidien
    type: io.kestra.plugin.core.trigger.Schedule
    cron: "0 6 * * *"
