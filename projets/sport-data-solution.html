Sport Data Solution – Pipeline BI & Avantages Salariés

Présentation du projet

POC (Proof of Concept) d'un pipeline de données end-to-end pour la société Sport Data Solution, permettant de calculer et d'attribuer automatiquement des avantages salariés liés à la pratique sportive. Ce projet comprend :

  • Ingestion des données RH : chargement et validation des fichiers salariés (salaire, domicile, mode de déplacement)
  • Simulation d'activités sportives : génération d'un historique de 12 mois d'activités sportives déclarées
  • Calcul des avantages : prime sportive (5% du salaire) et journées bien-être (5 jours si ≥ 15 activités/an)
  • Vérification Google Maps API : validation de la cohérence entre le mode de déplacement déclaré et la distance domicile-bureau
  • Dashboard Power BI : restitution visuelle des résultats pour les RH et la direction

Technologies utilisées

  • Python
  • Kestra (orchestration du pipeline)
  • SQL
  • Power BI
  • Docker
  • API Google Maps

Extrait du code


def calculer_avantages(salarie: dict, activites: list) -> dict:
    """Calcule les avantages sportifs d'un salarié."""
    salaire_brut = salarie["salaire_annuel"]
    mode_deplacement = salarie["mode_deplacement"]
    nb_activites = len(activites)

    modes_sportifs = {"marche", "running", "velo", "trottinette"}
    prime_sportive = (
        salaire_brut * 0.05
        if mode_deplacement in modes_sportifs
        else 0
    )

    jours_bien_etre = 5 if nb_activites >= 15 else 0

    return {
        "nom": salarie["nom"],
        "prime_sportive": prime_sportive,
        "jours_bien_etre": jours_bien_etre,
        "nb_activites_annuelles": nb_activites,
        "mode_deplacement": mode_deplacement,
    }
