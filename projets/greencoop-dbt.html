GreenCoop – Entrepôt de Données dbt & Docker

Présentation du projet

Projet de data engineering pour une coopérative verte (GreenAndCoop), mettant en place un entrepôt de données moderne à l'aide de dbt et Docker. Ce projet couvre :

  • Modélisation des données : conception de modèles dbt en couches (staging, intermediate, marts) pour structurer les données de la coopérative
  • Transformation SQL : écriture de requêtes dbt pour nettoyer, agréger et enrichir les données brutes
  • Containerisation : déploiement de l'environnement complet avec Docker et docker-compose
  • Tests de qualité : implémentation de tests de données automatisés pour garantir l'intégrité des résultats

Technologies utilisées

  • dbt (Data Build Tool)
  • SQL
  • Docker / Docker Compose
  • PostgreSQL
  • Data Warehouse

Extrait du code


-- models/marts/greencoop_summary.sql
WITH membres AS (
    SELECT
        membre_id,
        nom,
        region,
        date_adhesion
    FROM {{ ref('stg_membres') }}
),
commandes AS (
    SELECT
        membre_id,
        COUNT(*) AS nb_commandes,
        SUM(montant) AS total_achats
    FROM {{ ref('int_commandes_enrichies') }}
    GROUP BY membre_id
)
SELECT
    m.membre_id,
    m.nom,
    m.region,
    COALESCE(c.nb_commandes, 0) AS nb_commandes,
    COALESCE(c.total_achats, 0) AS total_achats
FROM membres m
LEFT JOIN commandes c USING (membre_id)
