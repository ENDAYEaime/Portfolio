Architecture Hybride Cloud AWS – InduTechData

Présentation du projet

Conception, modélisation et évaluation d'une infrastructure hybride cloud pour la société InduTechData, combinant environnements on-premise et cloud AWS. Ce projet comprend :

  • Architecture hybride : conception d'un schéma d'infrastructure combinant datacenter privé et services AWS (EC2, S3, RDS, VPN)
  • Traitement de données en temps réel : intégration de RedPanda (Kafka-compatible) pour le streaming et Apache Spark pour le traitement distribué
  • Évaluation de compatibilité : analyse de la compatibilité entre les systèmes existants et la nouvelle infrastructure cloud
  • Documentation technique : production de schémas d'architecture, rapports d'évaluation et recommandations

Technologies utilisées

  • AWS (EC2, S3, RDS, VPN)
  • RedPanda (streaming de données)
  • Apache Spark
  • Architecture hybride Cloud / On-Premise
  • Draw.io / SVG (schémas d'architecture)

Extrait de configuration


# Architecture hybride – composants principaux
infrastructure:
  on_premise:
    - service: PostgreSQL
      role: Base de données transactionnelle
    - service: RedPanda
      role: Streaming temps réel (Kafka-compatible)

  cloud_aws:
    - service: EC2
      role: Traitement Spark distribué
    - service: S3
      role: Data Lake – stockage des données brutes
    - service: RDS
      role: Base de données analytique managée
    - service: VPN Gateway
      role: Connexion sécurisée on-premise ↔ AWS

  flux_donnees:
    source: Capteurs IoT industriels
    pipeline: RedPanda → Spark → S3 → RDS → Reporting
