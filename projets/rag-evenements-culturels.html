Assistant RAG – Recommandation d'Événements Culturels

Présentation du projet

Développement d'un assistant conversationnel intelligent basé sur l'architecture RAG (Retrieval Augmented Generation), capable de recommander des événements culturels issus de la plateforme OpenAgenda. Ce projet intègre :

  • Collecte de données : extraction d'événements culturels via l'API OpenAgenda pour Paris et la France
  • Vectorisation sémantique : génération d'embeddings avec Mistral AI et indexation dans FAISS pour la recherche par similarité
  • Pipeline RAG : orchestration LangChain pour relier la recherche vectorielle à la génération de réponses contextualisées
  • Interface conversationnelle : l'utilisateur pose une question en langage naturel et reçoit des recommandations d'événements pertinentes

Technologies utilisées

  • Python
  • LangChain (orchestration RAG)
  • Mistral AI (embeddings & génération)
  • FAISS (recherche vectorielle)
  • OpenAgenda API
  • NLP / IA Générative

Extrait du code


from langchain.vectorstores import FAISS
from langchain.embeddings import MistralAIEmbeddings
from langchain.chains import RetrievalQA
from langchain.llms import MistralAI

def creer_assistant_rag(evenements: list[str]) -> RetrievalQA:
    """Crée un assistant RAG à partir d'une liste d'événements culturels."""
    embeddings = MistralAIEmbeddings(model="mistral-embed")
    vectorstore = FAISS.from_texts(evenements, embeddings)
    retriever = vectorstore.as_retriever(search_kwargs={"k": 5})

    llm = MistralAI(model="mistral-small", temperature=0.2)
    chain = RetrievalQA.from_chain_type(
        llm=llm,
        retriever=retriever,
        chain_type="stuff"
    )
    return chain
